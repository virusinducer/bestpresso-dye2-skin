# bestpresso-dye-skin

The Bestpresso skin with a DYE2 button, as a Decaid skin. Install `virusinducer/bestpresso-dye-skin` on
Decaid's skin screen. It installs as **Bestpresso + DYE2**.

The button only shows while the plugin `virusinducer/bestpresso-dye2` (**DYE2 for Bestpresso**) is
installed and enabled.

Everything is built in [virusinducer/bestpresso-dye2](https://github.com/virusinducer/bestpresso-dye2),
which tracks upstream Bestpresso and DYE2 daily. A workflow here republishes each new skin build as a
release within the hour, because Decaid installs skins from releases.
