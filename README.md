# bestpresso-dye2-skin

The Bestpresso skin with a DYE2 button, as a Decaid skin. Install `virusinducer/bestpresso-dye2-skin` on
Decaid's skin screen. It installs as **Bestpresso + DYE2**, and its version is exactly the Bestpresso
version it is built from.

The button only shows while the plugin `virusinducer/bestpresso-dye2-plugin` (**DYE2 for Bestpresso**) is
installed and enabled.

Everything is built in [virusinducer/bestpresso-dye2-plugin](https://github.com/virusinducer/bestpresso-dye2-plugin),
which tracks upstream Bestpresso and DYE2 daily. A workflow here republishes each new skin build as a
release within the hour, because Decaid installs skins from releases.
